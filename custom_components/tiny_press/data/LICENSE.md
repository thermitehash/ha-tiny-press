# Bundled data

All files in this folder were written for Tiny Press and are released under
the project's MIT license (see the repository's `LICENSE`).

| File | Contents | Source |
|---|---|---|
| `words.json` | Spelling and sight words by grade (K–5) | Compiled for Tiny Press from common English words. Single words are not copyrightable; no published list was copied. |
| `themes.json` | Short word lists per interest (space, dinosaurs, horses, …) used for word searches | Written for Tiny Press |
| `jokes.json` | Kid-friendly jokes and riddles (setup, punchline) | Written for Tiny Press, drawing on traditional schoolyard riddles that are folklore. No brands or copyrighted characters. |
| `facts.json` | Kid-friendly fun facts | Written for Tiny Press; each one checked against general reference sources |
