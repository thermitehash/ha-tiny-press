# v0.11.2 — Spelling from the to-do list only

## Changed
- **Spelling words come only from each kid's spelling to-do list.** The typed "Spelling words" box is gone from the kid profile. A list typed there before is ignored, so if you used it, add those words to a to-do list and pick it under **Configure → Edit a profile → Spelling list**.
- **A linked spelling to-do list is required.** The `words` field is removed from the `tiny_press.print` and `tiny_press.preview` actions; a script that still passes it fails with an "extra keys" error, so remove the field and add the words to the kid's list instead.

## Added
- On the card, the **Spelling** and **Spelling search** tiles show how many words are left on the kid's list, and are greyed out when the list is empty, every word is checked off, no list is chosen, or the list is unavailable. They update live as words are added or checked off.
- **Spelling word search** is back everywhere it was missing: a default tile on the card (next to Spelling), voice phrases in the Assist blueprint ("print a spelling word search for Rosie"; re-import the blueprint to get them), and the AI-agent print tool.
