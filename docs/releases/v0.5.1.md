# v0.5.1 — Card shows up in the card picker

## Fixed
- **The Tiny Press card didn't appear under "Custom" when adding a card.** It loaded through the frontend's extra-module hook, which doesn't make the card show up in the card picker on every setup.
  - Tiny Press now adds the card to your **dashboard resources**, the same way other card-shipping integrations do. It keeps the resource's version up to date on each update, removes duplicates, and removes the resource when the last Tiny Press printer is deleted.
  - Dashboards in YAML mode still get the card through the old hook; see the README if it doesn't appear.

After updating, restart Home Assistant and refresh the browser (or close and reopen the app). Then **Add card → Custom → Tiny Press** should be there.
