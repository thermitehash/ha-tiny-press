# v0.12.0 — Spelling crossword

## Added
- **Spelling crossword**: a criss-cross crossword built from the kid's spelling to-do list (up to 10 unchecked words per print).
  - **Clues written by AI:** with an AI task set up (Configure → Settings), each clue is written for the kid's reading grade: a simple definition, an opposite, or a fill-in-the-blank sentence. Clues follow the same kid-safe rules as AI jokes and stories, and a clue that contains its own answer (or a longer word built on it, like "friendly" for *friend*) is thrown out.
  - **Works offline:** without an AI task, when the AI doesn't answer, or for any clue that fails the checks, the clue is the word scrambled ("Unscramble: SUACEBE").
  - The same word list keeps the same AI clues (so a preview and its print match), and the AI isn't asked again for that list until Home Assistant restarts.
  - A word that shares no letters with the rest can't join the grid; it's listed under "Also practice" so it still gets written out.
  - Answer key, preview, kid-mode limits and the kid's name in the title work as for the other kid prints.
- Where to find it: a **Spelling crossword** button, a card tile next to Spelling search (greyed out like the other spelling tiles when the list has no words), `type: spelling_crossword` in the print, preview and voice actions, the AI-agent print tool, and Assist phrases ("print a spelling crossword for Rosie"; re-import the blueprint to get them).
