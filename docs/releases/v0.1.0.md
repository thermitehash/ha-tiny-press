# v0.1.0 — First print

The foundation: connect an Epson receipt printer and print mazes, notes and pictures.

## Added
- Config flow: host and port (default 9100) with a live connection and status test, then the paper width (80 mm = 576 dots, 58 mm = 420 dots) and an optional test page.
- DHCP discovery for Epson network devices. A device is only offered if it answers ESC/POS status requests on port 9100.
- Options: longest single print (default 600 mm) and status poll interval (default 60 s).
- Printer layer: raw ESC/POS over TCP port 9100 with asyncio and no drivers. Covers `ESC @`, banded `GS v 0` raster, text styles, `GS ( k` QR codes and `GS V` partial cut.
- One job queue, so prints never interleave. A job is retried once if the connection fails before any byte was sent, and never resent after a partial send.
- Status polling with `DLE EOT` 1, 2 and 4 (online, cover open, paper near-end, paper out). It is skipped while a job is printing.
- Rendering: every printout is drawn as a 1-bit image at the exact paper width. Text uses Atkinson Hyperlegible; grids and details use JetBrains Mono (both SIL OFL 1.1).
- Every printout ends with a footer: type, difficulty, date and a short ID such as `#K7Q2`.
- Maze generator (Wilson's algorithm) at easy 8×12, medium 12×18 and hard 16×28. The answer path is stored with the print.
- Actions: `tiny_press.print` (`maze`, `test_page`), `tiny_press.print_text` and `tiny_press.print_image`. Each returns response data (`print_id`, `type`, `length_mm`, `truncated`).
- The event `tiny_press_printed` fires for every print, successful or not.
- Entities: Online, Paper, Paper used (mm, total increasing) and Last print; Maze and Test page buttons; a Maze difficulty select.
- Diagnostics (with the host redacted) and a Repairs issue when the printer has been offline for more than 24 hours.
- Brand images in `custom_components/tiny_press/brand/`.
- CI: hassfest, HACS, Ruff, pytest with coverage, a translations check and a version-bump check. The release workflow publishes a tag and release after Validate passes on `main`.
