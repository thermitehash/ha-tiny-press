# v0.4.0 — Adult puzzles

Sudoku, crosswords and cryptograms for the grown-ups, plus a puzzle pack with all three.

## Added
- **Sudoku (9×9)** with exactly one solution, graded by the solving techniques it needs rather than the number of clues:
  - Easy: solvable with singles only, and at least 34 clues.
  - Medium: needs pairs or box/line reasoning.
  - Hard: needs more advanced techniques.
- **Criss-cross crossword:** 8 (easy), 10 (medium) or 12 (hard) interlocking words on a grid no bigger than 13×13, with numbered Across and Down clues and answer lengths.
  - Clues come from a bundled bank of 213 everyday words, each with a straight clue and a wordplay clue in NYT style.
  - Easy uses the straight clues, hard uses the wordplay clues, and medium mixes them.
- **Cryptogram:** a public-domain quote where every letter is swapped for another, and no letter ever stands for itself.
  - Easy gives away 2 letters, medium 1, hard none. Each code letter has a blank under it for writing.
  - It doesn't repeat recently printed quotes.
- **Puzzle pack:** sudoku, crossword and cryptogram in one print with one cut. Each puzzle has its own ID and answer key.
- **Answer keys** for all three, via `print_answers` or the Answers button.
- **Adult profile** and **Sudoku difficulty** selects. Adult puzzles use the adult's default difficulty unless a `difficulty` is given. Sudoku uses the Sudoku difficulty select.
- New buttons: Sudoku, Crossword, Cryptogram, Puzzle pack. New `print` types: `sudoku`, `crossword`, `cryptogram`, `puzzle_pack`.
- **Dashboard card:** adult buttons with Adult and Sudoku chips. Kid mode never shows adult puzzles.
- Adult puzzles don't count toward kid-mode limits.
- **Spelling list from a to-do list:** pick any `todo` entity in a kid's profile, one word per item.
  - Spelling practice and Spelling word search use the unchecked words, so checking a word off marks it learned. When every word is checked off, you get a friendly message instead of an empty sheet.
  - Add words from the Home Assistant app, a dashboard to-do card, or Assist ("Add *because* to Rosie's spelling list").
  - Words passed to the action come first, then the to-do list, then the typed list. If the to-do list can't be read, the typed list is used.
  - Lists longer than 15 words are sampled, so each sheet practices a different 15.

## Content sources
- **Quotes:** 27 public-domain quotes from Theodore Roosevelt (from his pre-1931 books, as collected by the National Park Service), John Muir (works published before 1931 only), Abraham Lincoln and Shakespeare. Each one is sourced to an NPS page.
- **Crossword clues:** written for Tiny Press (MIT). No openly licensed collection of NYT-style clues exists, so these are original, like the bundled jokes.
