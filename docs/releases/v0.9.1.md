# v0.9.1 — Feed auto-print, and feeds print newest first

## Added
- **Feed auto-print** (off by default): Configure → **Edit a feed** → **Auto-print new items** prints a short slip each time that feed adds an item.
  - **Check every:** 15 minutes by default (5–1440).
  - **First check:** only notes what's already in the feed, so no backlog prints.
  - **Bursts:** one slip per new item, at most 3 per check. Items older than 12 hours never auto-print.
  - **Quiet hours per feed:** 9 PM–7 AM by default. Either skip items that arrive then, or print up to 3 of them when quiet hours end. Clear both times to print at any hour.
  - **QR code on auto slips:** optional.
  - **Printer off:** a slip that can't print waits for the next check.
  - **Limits:** auto slips never count toward kid-mode limits.
- **Edit a feed** also changes how many items the Print feed action and buttons print.

## Fixed
- Feed prints, the morning slip's headlines and voice or AI feed requests now show the **newest** items first. Some feeds, such as the New York Times' section feeds, list stories in editors' order, so an older story could print ahead of today's. Items without a date keep their feed order, after the dated ones.
